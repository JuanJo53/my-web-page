# Tech Stack: My Online CV

## Frontend
-   **Core Framework:** React 18 (Functional Components & Hooks).
-   **Routing:** React Router v6.
-   **Styling:**
    -   Sass (.scss) for component-level styling.
    -   CSS for global styling.
    -   Material UI (MUI) v5 & React Bootstrap v2 for UI components.
-   **Icons:** FontAwesome v6.

## Backend & Infrastructure
-   **Platform:** Firebase.
-   **Database:** Cloud Firestore (NoSQL) for dynamic content management (Projects, Experience, etc.).
-   **Storage:** Firebase Storage for hosting images and documents.
-   **Functions:** Firebase Cloud Functions (Node.js) for server-side logic (e.g., contact form processing).
-   **Hosting:** Firebase Hosting.

## Build & Tooling
-   **Bundler:** Webpack 5 (Custom Config).
-   **Transpiler:** Babel.
-   **Linting:** ESLint (Airbnb configuration).
-   **Automation:** npm scripts.
